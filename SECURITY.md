# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately, using either:

- GitHub's private vulnerability reporting: open the **Security** tab of this repository, then **Report a vulnerability**;
- or email brume.app.team@gmail.com.

Please include what you found, how to reproduce it and which part of Brume is affected. We aim to acknowledge your report within 7 days.

## Supported versions

Brume is in early development. Only the `main` branch receives security fixes.
